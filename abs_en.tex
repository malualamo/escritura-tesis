\chapter*{\runtitle}

\noindent 

Hybrid visual search (the task of locating in a scene any one of a set of possible targets held in memory) can be described as a Bayesian inference process in which each eye fixation updates the observer's belief about the target's location. The nnELM (Neural Network Entropy Limit Minimization) computational model \citep{ruarte2025} formalizes this process by combining deep neural networks with an expected entropy minimization criterion to select the next fixation. Separately, the regularized-regression \textit{Temporal Response Functions} (TRFs) framework \citep{care2025} allows linking fixation-level predictors to the electroencephalography (EEG) signal recorded continuously during the task. This thesis set out to bridge both lines of work: to design and extract, from the internal maps of the nnELM model, variables that quantify different aspects of the visual search process, and to evaluate whether these variables have correlates in brain activity recorded over the HSEM (\textit{Hybrid Search Eye Movements}) dataset, which includes simultaneous eye movement and EEG recordings from 42 subjects during a hybrid search task on natural scenes. Twenty variables were designed and extracted, organized into five conceptual categories, their consistency with the expected dynamics of the search process was validated, and their contribution to predicting the EEG signal was evaluated through an incremental model-building scheme, diagnosed via VIF and assessed using $\Delta$AIC and TFCE. Significant neural correlates were found in variables from four of the five defined categories, particularly in variables related to visual similarity with the target, the state of the Bayesian process, and the quality of the subject's decision relative to the model's optimal strategy. These results provide evidence that the TRF framework constitutes an appropriate tool for linking latent variables from Bayesian computational models with neural activity during visual search tasks.

\bigskip

\noindent\textbf{Keywords:} hybrid visual search, Bayesian inference, electroencephalography, eye movements, nnELM, temporal response functions.
